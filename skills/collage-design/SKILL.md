# Collage Design

目标：把用户的设计目标和文本材料，转化为所选平台中的可编辑设计，并保留后续返修需要的来源、对象和版本记录。

先读 [默认设计与编辑约定](references/preferences.md)。新任务按下列流程推进；返修任务直接读取交接记录和最新设计，进入局部修改，不重新发需求问卷。

## 收束输入

从本轮及已有上下文提取：

1. 设计目标：易拉宝、海报或社媒图片；尺寸／发布位、页数、用途。实体尺寸使用 cm，屏幕图片使用比例和所需像素。
2. 制作平台：Canva 或 Figma；已有稿／母版入口如有则沿用。
3. 文本材料：现成文案、文件或可访问资料。转换成一级标题、二级标题、三级标题、正文、CTA 与辅助信息，保留原意和事实限定。
4. 意向配色：可选。用户未指定时，由主题和选用素材建立一套色板，不强制追问。

只询问影响结果且确实缺失的信息，提供类目和示例选项；已有答案不重复问。不要把文本框分框、connector 操作习惯和母版继承再次列为需求项。

## 选定平台、冻结路线并检查连接

用户明确选择 Canva 或 Figma 后，立即在本次任务记录中保存 `platform` 与 `platform_locked: true`，并选择对应的制作、保存和返修路线。上下文已明确平台时直接冻结，不重复确认。

- Canva：读取 [Canva 路线](references/canva.md)，加载当前环境可用的 Canva 编辑指南。
- Figma：读取 [Figma 路线](references/figma.md)，按工具要求加载 `figma-use` 等必要指南。

两种制作方式都由本 skill 支持；单次任务冻结后只执行选中的分支，不调用另一平台作为搜图、制稿或返修兜底。搜图、素材整理、拼贴主视觉与主题色属于 Codex 的共享工序，独立于两个设计平台，无需用户另选搜图平台。

检查所选平台的实际工具、授权状态及目标文件可访问性。读取成功不能当作写入已验证；首次实际制作成功后记录写入结果。缺连接时指出具体缺项，保持平台冻结；可继续独立的材料整理工作，不改用 Computer Use 或另一设计平台。

## 搜真实图片并建立主题色

读取 [素材与交接](references/assets-and-handoff.md)。沿用 Codex 已有的网页／图片检索工作流：先整理用户已有素材，再根据文本提炼通用对象、场景、器物与细节关键词检索真实图片。Canva 和 Figma 共用这一步，不依赖平台自带图库或其搜图接口，也不要求用户另装搜图 connector。保密文本不直接作为公开搜索词。

检查候选图片内容、来源及可用范围，记录选用理由。不要把搜索缩略图或生成照片当作已核实的原始素材。

有意向配色时围绕它组织素材；未指定时从内容和照片建立主色、辅色、强调色、文字色与纸色。以可读性和主体突出为准，不必机械采用照片中面积最大的颜色。

## 制作拼贴与排版

首次制作先读 [视觉示例与素材链](references/visual-examples.md)，用图像查看工具实际查看对应的关系图与成品；再按 [选材与层次判断](references/composition-decisions.md) 决定真实素材、黑白／彩色及最前景主体。示例用于学习视觉关系，不把案例人物、角色或矩形占位直接带入新设计；返修时无需重复加载已看过且未变化的参考。

先确定内容容量和阅读顺序，为标题、正文与 CTA 留出空间，再组织素材。Codex 的共享素材工序用真实图片的复制、裁切、错位及图层关系制作拼贴主视觉，整理背景、需要独立摆放的前景素材和主题色；按当前图像工具规则执行并核查结果。素材产物随后交给已冻结的平台路线导入、组合并排版。

优先保持图像来源可追溯以及文字独立可编辑。若另行使用生成式工具，仅在用户允许的范围内处理，不把生成内容称为实拍，不承诺生成式编辑能保持人物或产品细节完全不变。

通过已冻结的平台路线完成首稿：Canva 使用母版／创建或导入后精修；Figma 上传素材后组织原生 Frame、文本和图层。两条路线各自完成可编辑排版、预览和保存。默认推进一个完整方向；用户要求候选时再输出候选。按最新母版继承字体、文本分框和分组；无母版时用按语义组织的起稿方案，并记录本次决定。

检查文案准确性、层级、换行、溢出、对齐、纸片是否完整承载标题、图层遮挡、安全区域及各页一致性。核对保存状态，再给出预览和可编辑入口；已要求导出时同步交付相应文件。

## 交付与返修

保存本次简报、色板、素材清单、目标文件及对象映射、检查结果与交接说明。不能把未提交事务说成已保存。

首稿交付后结束本轮，等待用户新指令，不自动建立定时任务。返修时：

1. 读取平台冻结记录，沿用同一分支；重新读取当前文件和受影响页面，识别人工修改。
2. 将反馈转换成具体页面、字段或对象上的改动。
3. 只修改请求涉及的内容；保留最新人工字体、分框、间距及图像调整。
4. 检查受影响画面与保存状态，更新交接记录。

连接失败、接口限制、额度不足或排版困难均不解除平台冻结。先修复所选平台的问题，或交给该平台内的人工微调。只有用户明确要求换平台才更新冻结记录、记录迁移关系并进入另一分支；不得覆盖原平台已有成果。冻结的是制作平台，不是内容、配色或版式，后者仍可按返修指令修改。
