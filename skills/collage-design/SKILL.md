# Collage Design

将设计目标和文本材料转化为 Canva 或 Figma 中的可编辑拼贴设计。先读 [设计与编辑约定](references/preferences.md)；返修从最新设计及交接记录开始。

**执行约束：通过官方 MCP／connector 操作设计平台，默认不调用 Computer Use。平台确定后，必须先完成连接与账号的信息同步，再进入搜图、生图、上传或排版。**

## 收束输入

从已有上下文提取以下信息，仅补问影响结果的缺项，并提供类目和示例选项：

1. 设计目标：易拉宝、海报或社媒图片；尺寸／发布位、页数、用途。实体尺寸使用 cm，屏幕图片使用比例和所需像素。
2. 制作平台：Canva 或 Figma；已有稿／母版入口如有则沿用。
3. 文本材料：现成文案、文件或可访问资料。转换成一级标题、二级标题、三级标题、正文、CTA 与辅助信息，保留原意和事实限定。
4. 意向配色：可选。用户未指定时，由主题和选用素材建立一套色板，不强制追问。

## 强制前置：连接、账号与执行方式

记录用户选择的 `platform`、`platform_locked: true` 与 `execution_mode: mcp`。按 [连接与账号核验](references/connector-preflight.md) 完成检查，只加载所选分支：

- Canva：读取 [Canva 路线](references/canva.md)，加载当前环境可用的 Canva 编辑指南。
- Figma：读取 [Figma 路线](references/figma.md)，按工具要求加载 `figma-use` 等必要指南。

向用户简短同步：所选平台、官方 MCP 连接状态、授权账号及信息来源、团队／工作区、目标文件或新建位置、读写状态、本次执行方式。工具发现、网页登录和文件拥有者均不能代替授权身份核验；另一平台未选用时无需检查。

所需官方 MCP 工具不可用、账号或连接未明确、与指定账号不符、目标工作区有歧义时，暂停依赖该信息的制作，仅整理已有文本并补问缺项。结果明确且符合已知要求时同步后继续，无需重复批准；无法提前验证写入时标为待实际操作验证。MCP 失败不自动转用浏览器、桌面操作或另一平台。

## 搜真实图片并建立主题色

按 [素材与交接](references/assets-and-handoff.md) 整理已有素材，使用宿主网页／图片搜索检索真实照片，独立于设计平台图库。搜索词采用通用主题词，避免泄露保密文本。核对原图、来源与可用范围，并记录选用理由。

围绕意向配色或素材建立主色、辅色、强调色、文字色与纸色，以可读性和主体突出为准。

## 制作拼贴与排版

首次制作时实际查看 [视觉示例与素材链](references/visual-examples.md) 中相关图片，按 [选材与层次判断](references/composition-decisions.md) 确定素材角色、黑白／彩色及前景主体。

先安排阅读顺序与文字空间，再通过裁切、重复、错位和遮挡组织拼贴，分别准备背景和独立前景。

在 Codex 中可按 [图像模型调用](references/assets-and-handoff.md#codex-图像模型调用) 使用当前内置生成／编辑能力制作主视觉、纹理或局部返修，遵循可用 `imagegen` skill 与实际工具 schema。尊重仅实拍或原像素要求，区分真实、生成与生成式编辑素材。

将素材导入已选平台完成排版：Canva 创建／导入后精修，Figma 使用原生 Frame、文本和图层。继承最新母版的字体、文本分框与分组；无母版时按语义组织文本。默认交付一个完整方向，候选数量依任务要求。

检查文案、层级、换行、溢出、对齐、纸片承载、遮挡、安全区域及多页一致性，并验证保存结果。

## 交付与返修

交付预览、可编辑入口和已要求的导出文件；将简报、色板、素材来源、对象映射及检查结果留在私有任务目录。交付后等待新的返修指令。

返修沿用已选平台和有效的前置记录；新会话、重连或账号／工作区变化时按核验规则更新信息。回读当前页面以保留人工修改；将反馈定位到具体对象，局部调整后检查画面与保存状态，更新交接记录。
