# 连接与账号核验

制作前必须核对所选平台的官方 MCP 连接与授权身份，并向用户同步。此步骤适用于 Canva 和 Figma；未选的平台不调用、不要求连接。

## 最小检查

1. **工具与连接**：发现所选官方 connector 的必要工具。优先复用本会话成功的身份或只读调用；否则使用身份接口或与目标相关的最小只读请求。工具出现在列表中仅表示可调用，不证明授权有效。
2. **授权身份**：获取当前授权账号的显示名或可辨识标识，按需要核对团队／工作区与用户指定账号。身份来源可为 MCP 身份结果、宿主提供的可信连接元数据，或用户对连接设置的明确确认。文件拥有者和浏览器登录账号不能作为 MCP 身份证据。
3. **目标与能力**：已有文件用官方工具读取目标元信息；新建文件确定账号和目标位置，按当前创建工具规则选择工作区。区分“读取成功”“工具支持写入”“实际写入成功”。前置检查不创建探测稿、不启动编辑事务；写入权限无法只读核实时记为待首次实际操作验证。
4. **同步与记录**：用一段话或小表报告下列字段，再进入素材制作。记录保存在私有任务目录，不放入公开 skill。

| 字段 | 同步内容 |
| --- | --- |
| 平台与执行方式 | Canva 或 Figma；官方 MCP；Computer Use 默认关闭 |
| 连接状态 | 工具核验成功／用户确认、API 待验证／未连接／授权失败 |
| 授权账号 | 显示名或脱敏账号标识；标明工具核验或用户确认 |
| 工作区与目标 | 团队／工作区、目标文件或新建位置；不适用时注明 |
| 读写状态 | 已核实的读取、可用的制作能力，以及尚待验证的写入 |

当前工具没有身份接口时，请用户确认**宿主连接设置中授权的账号**，而非网页当前登录账号。所需官方 MCP 工具已发现、但无法进行合适的只读连接检查时，可接受用户对宿主连接状态的明确确认，必须标为“用户确认、API 待验证”；缺失确认时不继续制作。工具缺失或已返回授权失败、权限拒绝、账号不符时，用户口头确认不能将失败改为通过，应先修复或重新授权。

身份和目标明确且没有已知阻碍时，同步后继续任务，不把信息同步变成每次操作的批准步骤。身份未知、多个目标工作区未选定或账号不符时，只补问缺项；等待期间可整理已有文本，不进行生图、上传或平台写入。平台迁移仅在用户明确改选后进行，并重新核验。

## Computer Use 边界

- 默认使用官方 MCP 完成创建、读取、上传、排版、导出和保存。不要为了检查连接或登录，调用浏览器／桌面控制、扫描已开标签页或截取桌面。
- MCP 缺失、失效、限流或功能不支持时，报告具体缺项，优先连接修复或由用户在所选平台内人工接续；不自动启动 Computer Use。
- 只有用户明确要求 Agent 代操作界面时，才可在说明具体缺口后，将 Computer Use 限定到该步骤；仍需核对操作账号和目标，不扩展为全流程界面自动化。
- MCP 返回的缩略图、画布截图，以及本地素材查看不属于 Computer Use，仍用于必要的视觉检查。网页／图片检索使用宿主搜索工具。

## 减少重复调用

同一会话内复用未失效的核验结果；重连、授权失败或账号／工作区变化时重新核验。进入新会话需刷新连接与身份；只更换目标文件时核对新文件权限即可。

只加载所选平台的必要工具和指南，优先小范围元信息；不遍历账号资源来推测身份。相关编辑按工具规则批量执行，预览复用已返回的图片；仅在内容变化、失败或证据不足时补查。
