# 拼贴视觉示例与素材链

首次制作时，用图像查看工具打开相关关系图、成品与中间素材，配合 [选材与层次判断](composition-decisions.md) 理解色彩和前后关系。

示例文字和私有标识已替换为矩形，部分肖像已隐藏。学习图经图像编辑，可能存在局部像素差异，适用于构图参考；占位矩形不属于新任务内容。素材来源与使用范围见 [索引](visuals/sources.md) 和 [说明](visuals/NOTICE.md)。

## A. 长幅易拉宝：环境融入背景，少量彩色主体在前

![长幅易拉宝素材到成品的关系](visuals/rollup/flow.png)

摄影原片 → 环境拼贴与纸片 → 独立彩色前景 → 原生文字排版 → 脱敏学习图。

| 位置 | 打开的图片 | 重点观察 |
| --- | --- | --- |
| 输入 | [15 张原片索引](visuals/sources.md) | 人物、场地、器材、手机、摄像机、社交场景的搭配 |
| 环境拼贴 | [环境裁片](visuals/rollup/stages/ambient-collage.jpg) | 同源复制、尺度与裁切变化 |
| 文字承载层 | [纸片与背景](visuals/rollup/stages/paper-background.jpg) | 大部分图像融入背景；纸片提供文字对比与空间 |
| 最前景 | [人物一](visuals/rollup/stages/foreground-01.png)、[人物二](visuals/rollup/stages/foreground-02.png) | 从原片分离主体，保留彩色；纸边让其位于最前 |
| 输出 | [脱敏最终易拉宝](visuals/rollup/final-redacted.png) | 标题、正文与前景的层级 |

本例画幅为 80 × 200 cm。素材数量和位置是案例选择；中间图与最终图用于观察材料关系，不能作为精确重建参数。

## B. 双页社媒海报：共享底图与版式

![双页海报素材到成品的关系](visuals/poster/flow.png)

生成概念背景 ＋ 角色图片 → 前景剪纸与共享底图 → 系列排版 → 两张脱敏学习图。

| 位置 | 打开的图片 | 重点观察 |
| --- | --- | --- |
| 初始输入 | [概念背景](visuals/poster/sources/concept-background.png)、[角色图片](visuals/poster/sources/character.png) | 区分生成概念图与既有角色素材 |
| 独立前景 | [角色剪纸](visuals/poster/stages/character-cutout.png) | 主体轮廓、暖色与紫色环境的差异 |
| 共享底图 | [组合底图](visuals/poster/stages/assembled-background.png) | 主体、纸张和文字空间的关系 |
| 输出 A | [脱敏海报 A](visuals/poster/final-a-redacted.png) | 大标题、两块正文纸片、页脚的阅读顺序 |
| 输出 B | [脱敏海报 B](visuals/poster/final-b-redacted.png) | 相同底图与层次适配不同文案长度 |

本例为 3:4 社媒竖图，展示暖色主体与紫色环境的对照。概念背景属于生成素材，真实图片任务仍应按检索路线选材。
