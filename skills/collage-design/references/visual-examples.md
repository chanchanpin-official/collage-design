# 拼贴视觉示例与素材链

首次制作时，先看与目标接近的关系图，再实际打开成品和相关中间素材。阅读 [选材与层次判断](composition-decisions.md)，明确为什么选这些图片、为什么去色，以及为什么只有少量主体浮于最前。

这些是已有最终导出稿的脱敏学习图：文字、字标与二维码已改为实心矩形；长幅图中间的三个人像也已隐藏，其源照片不随包发布。脱敏使用图像编辑，可能有局部像素差异；用于学习构图、层次和材料关系，不作为精确坐标、字体或可编辑母版。矩形条不是新任务的成品文案。

上游图片保留素材本身，用中性编号命名并去除文件元数据。部分第三方素材自身带有器物或服装标记，不是项目文案。真实任务的人名、履历、联系方式、项目链接与原始设计文件均未收录。

## A. 长幅易拉宝：环境融入背景，少量彩色主体在前

![长幅易拉宝素材到成品的关系](visuals/rollup/flow.png)

15 张摄影原片 → 42 个环境裁片 → 统一暖色的背景与纸片 → 独立彩色人物前景 → 原生文字与最终排版 → 脱敏学习图。

| 位置 | 打开的图片 | 重点观察 |
| --- | --- | --- |
| 输入 | [15 张原片索引](visuals/sources.md) | 人物、场地、器材、手机、摄像机、社交场景的搭配 |
| 环境拼贴 | [环境裁片](visuals/rollup/stages/ambient-collage.jpg) | 同源复制、尺度与裁切变化，场景保持水平 |
| 文字承载层 | [纸片与背景](visuals/rollup/stages/paper-background.jpg) | 大部分图像融入背景；纸片提供文字对比与空间 |
| 最前景 | [人物一](visuals/rollup/stages/foreground-01.png)、[人物二](visuals/rollup/stages/foreground-02.png) | 从原片分离主体，保留彩色；纸边让其位于最前 |
| 输出 | [脱敏最终易拉宝](visuals/rollup/final-redacted.png) | 标题、正文与前景的层级；三个人像位置已隐藏 |

本例画幅为 80 × 200 cm。学习其层次关系，不机械套用原片数量、纸片数量、固定前景位置或灰色人像占位。现存中间产物来自同一制作链；最终输出包含后续人工修改，不将历史源稿与最终导出视为完全相同版本。

## B. 双页社媒海报：共享底图，继承人工排版

![双页海报素材到成品的关系](visuals/poster/flow.png)

生成概念背景 ＋ 角色图片 → 角色剪纸 → 替换主体后的共享底图 → 第一页人工排版 → 第二页继承版式并更换文案 → 两张脱敏学习图。

| 位置 | 打开的图片 | 重点观察 |
| --- | --- | --- |
| 初始输入 | [概念背景](visuals/poster/sources/concept-background.png)、[角色图片](visuals/poster/sources/character.png) | 这是一条含生成图与既有角色素材的历史链，区别于实拍拼贴 |
| 独立前景 | [角色剪纸](visuals/poster/stages/character-cutout.png) | 主体轮廓、暖色与紫色环境的差异 |
| 共享底图 | [替换后底图](visuals/poster/stages/assembled-background.png) | 保留纸张和文字区，仅替换右上主体 |
| 输出 A | [脱敏海报 A](visuals/poster/final-a-redacted.png) | 大标题、两块正文纸片、页脚的阅读顺序 |
| 输出 B | [脱敏海报 B](visuals/poster/final-b-redacted.png) | 相同底图与层次，不同文案长度；继承最新人工版式 |

本例为 3:4 社媒竖图。参考其主题主体、环境与正文的关系；不默认采用例中的角色、人物或配色。用户选择真实图片任务时，仍按真实检索路线选材，不能用本案例的生成背景冒充实拍。
