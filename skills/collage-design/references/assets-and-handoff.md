# 素材与交接

## 搜图与拼贴

这是 Codex 的共享工序，独立于制作平台。使用宿主已有的网页／图片搜索能力处理真实素材；不以 Canva 或 Figma 的图库、连接状态或搜图接口为前提，也不把另装搜图平台作为用户步骤。素材整理与主视觉完成后，才交给已冻结的平台路线导入和排版。

优先用户自有、允许用于本任务的照片，再检索有明确来源与可用范围的真实图片。将原文抽象成对象、场景、器物、活动和纹理词检索，使用主题词而非机密项目名、内部原话或未公开细节。

查看原始来源页与图片内容，保留原始资源记录；不将图片搜索缩略图当作原图，不把下载成功当作使用范围已核实。记录来源、作者信息如有、可用范围、素材角色和本地／平台资产标识。来源不清楚的候选不当作已核实成品素材。

按 [选材与层次判断](composition-decisions.md) 为选中图片记录环境／连接／最前景角色、选用理由、黑白或彩色处理、同源裁片关系和前景优先级。先看 [视觉示例](visual-examples.md) 的素材到成品关系，再将这套判断应用于本次主题；参考图中的人物和角色不是默认可复用的任务内容。

组合应保持主体事实可辨认。裁切、复制、遮挡、去色和纸张承载用于构图，不能凭空造出用户未提供的真实产品功能、人员身份或项目实景。

## Codex 图像模型调用

在 Codex 中运行时，先查看当前会话是否提供内置图像生成／编辑工具；可用时加载当前 `imagegen` skill，并按实际 schema 调用 `image_gen` 等入口。可以在任务范围内主动生成或编辑素材，无需用户为每次调用单独重复授权。模型名称、版本与可选参数以宿主实际暴露的能力为准；不因记忆中的产品名称指定不存在的模型，也不把这里写成固定模型依赖。

1. **明确用途**：根据任务选择真实图片拼贴的图像编辑、纸张与纹理、概念背景、主题主视觉或局部返修。用户要求仅用真实照片或保留原始像素时，继续使用原图及平台原生组合，不能用生成照片替代检索结果。
2. **提供参考**：编辑本地图片前先查看它。区分待编辑目标、风格参考和需要合成的素材；明确需要保留的主体、配色、构图、前后层次，以及只允许修改的区域。检索得到的真实原片继续保留来源。
3. **为排版留白**：生成背景或主视觉时留出标题、正文和行动入口的位置。正式文案继续作为 Canva／Figma 原生文本排版，不把一整张带文字的生成海报当作可编辑成品。
4. **检查与落盘**：查看输出是否符合主题、黑白／彩色层次及主体选择，是否改变真实人物或产品细节、生成多余文字或遮挡正文。将选用结果保存到本次私有任务目录，再通过已选平台的上传入口导入。
5. **记录来源类型**：在素材清单区分 `real`、`generated`、`generative_edit`，保存原片来源、输入素材关系、提示词和输出文件。工具返回模型信息时再记录，不推测未返回的后端版本。

Codex 内置工具路线不要求另配 API key。工具不可用或失败时，说明当前缺项；仅在用户明确选择 CLI／API 路线后，才按 `imagegen` 指南处理该路线的配置，不静默换成需要密钥的工具链。其他宿主以其实际图像能力为准，不假设存在 Codex 的工具。

图像生成与编辑不解除 Canva／Figma 平台冻结，也不意味着已经在设计平台保存。主视觉输出经检查后，再回到同一平台完成可编辑排版、保存和后续返修。

## 任务目录

Skill 包存通用流程及明确允许公开、已脱敏的视觉学习图。每次真实任务在用户项目内单独建目录，按需要保存：

| 文件／记录 | 最少内容 |
| --- | --- |
| brief.md | 目标、用途、尺寸／发布位、所选平台、分层文案与优先级 |
| assets.json | 原始来源页、资源位置、图片角色、可用范围记录、选用状态、平台 asset ID |
| design-state.json | platform（canva／figma）、platform_locked、对应路线、目标链接与 ID、母版、页／Frame／关键文字对象映射、颜色角色及色值、当前阶段 |
| handoff.md | 最新保存结果、人工修改需保留的内容、检查结论、输出文件、具体待办 |

这些文件在任务执行时生成，不在 skill 包内预置真实内容或凭据。

用户明确选平台后立即保存冻结记录。记录所依据的选择即可，不强制用户二次确认。每轮返修先恢复此记录；不因工具故障或功能差异更改平台。用户明确改选时才更新记录，并保留旧平台成果入口及迁移关系。文件级路径、颜色和文字仍可按请求更新，平台冻结不冻结设计内容。

阶段可以记录为：需求收束、素材准备、首稿制作、待保存确认、已保存待返修。只有成功保存后才能标记已保存。不要把“待保存确认”与“等待后续返修”混为一谈。

返修时在线最新稿优先于本地记录；本地对象映射仅用于定位。节点不再存在或页面结构变化时重新读取，禁止拿旧映射盲写。长期交接不存 OAuth 信息、签名上传 URL、临时事务或其他凭据。

交付给用户：预览、可编辑入口、简短的设计说明，以及已要求的导出文件。素材溯源保存在交接资料，不自动印在海报或正文画面上。
