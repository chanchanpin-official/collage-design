# 默认设计与编辑约定

以下为可复用的起稿与编辑默认值；用户本次明确要求优先。不要把项目特有配色、人物、品牌或文案带到其他项目。

- Agent 通过所选平台 connector 操作，保留用户自己在编辑器中人工调整的方式。
- 直接复用用户确认的母版对象，优先级：本次修改指令 ＞ 最新人工稿 ＞ 既有母版 ＞ 历史源文件。
- 一级、二级、三级标题和正文保持原生可编辑。分几框、如何合并以母版实际结构为准，不根据截图重新逐行造框。
- 新增区域尽量复制同级同类对象。没有现成母版时，起稿可按语义块组织；具体分框以内容结构与用户要求为准，不预设一行一框或一段一框。
- 同系列放在同一文件，用 Canva 页面或 Figma Frame 管理；以最新确认页同步公共样式，保留各页差异内容。
- 真实照片构成拼贴；从主体、环境、器物、局部细节等不同类别取材。素材数量由画幅、信息量与构图决定，不预设固定数量。
- 先为素材分配环境、连接或最前景角色，再决定黑白／彩色。大部分环境照片去色或统一主题色后融入底纹，少量最能代表主题、轮廓清楚且适合引导阅读的主体保留彩色并置于最前。具体判断见 [选材与层次](composition-decisions.md)，不要让每张图都同样醒目。
- 默认采用复制照片、黑白与彩色对照、裁切错位、撕纸质感和背景融合，少量重点主体在前景。场景背景默认保持水平；本次用户另有要求时调整。
- 标题要落在承载纸片或色块内部；删去没有内容作用的装饰小字和干扰阅读的分割线。
- 人工修改后先回读，避免旧 HTML、脚本、对象坐标覆盖最新修改。同一目标页避免人工和 Agent 同时写入。

用户的稳定偏好与单次任务决定分别记录在用户自己的私有配置和任务交接中，不自动写入公共 skill 包。
