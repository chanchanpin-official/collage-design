# 默认设计与编辑约定

以下约定用于起稿与编辑，当前任务要求优先。个人偏好保存在私有配置中，按需读取。

- 使用所选平台 connector 制作，支持编辑器内的人工接续。
- 版本依据：当前指令 ＞ 最新确认稿 ＞ 既有母版 ＞ 历史源文件。
- 文字保持原生可编辑，沿用母版的分框、字体与分组；新增内容优先复用同类对象，无母版时按语义组织。
- 同系列使用一个文件的多页或多个 Frame，共享样式并保留差异内容。
- 从主题、环境、器物与细节取材，按画幅和信息量决定数量；依据 [选材与层次](composition-decisions.md) 分配黑白／彩色与前景角色。
- 裁切、重复、错位、纸张边缘与遮挡服务阅读层级；标题完整落在承载区域，装饰不干扰正文。
- 人工和 Agent 接续编辑时先回读最新状态，避免并发写入和旧稿覆盖。
