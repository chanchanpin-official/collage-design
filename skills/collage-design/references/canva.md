# Canva 路线

工具名在不同宿主中有不同前缀，按实际 schema 调用，不编造参数。执行现有稿编辑前加载当前 Canva 编辑 skill。

适用于 `platform: canva`、`platform_locked: true` 的任务。接收独立准备的素材，在 Canva 内完成制作、保存和返修。

## 连接与账号前置

先完成 [连接与账号核验](connector-preflight.md)。发现官方 Canva MCP 工具后，使用当前可用的身份接口或可信连接元数据；没有这些能力时，请用户确认宿主连接设置中的授权账号和团队。不得虚构 Canva 的 `whoami` 接口，也不得将 `get-design` 返回的设计拥有者当作当前授权用户。

有目标设计时，通过 `get-design` 等当前只读接口核对访问；完整分享链接和短链接按当前工具规则处理。无目标时，只使用当前 schema 允许且与任务相关的轻量只读检查；若没有合适入口，按前置规则取得用户的连接确认并标记 API 待验证。先同步连接、账号与目标，再开始首稿；不通过网页登录或新建设计探测连接。

## 首稿

1. 复用前置检查已取得的目标信息，读取所需页面及预览，定位母版；没有目标时使用当前可用的创建入口。
2. 按所选目标明确尺寸。已有设计优先复制母版；同系列保持一个文件内多页。
3. 无母版的首稿可使用当前创建设计工具，或导入本次生成的 HTML／ZIP。需要精确分框与指定图片时优先验证导入路线；每页使用工具要求的 `data-document-role="page"` 标记。导入后核对尺寸、中文字体、图层和独立文字对象，不能保证 HTML 的所有效果都保真。
4. 将共享素材工序产出的拼贴背景、独立前景和主题色应用到 Canva。素材使用工具提供的直接文件上传方式；已有公开 URL 可直接引用。不要为了导入把私有文件临时发布到公开图床。
5. 创建工具存在时按其当前规则使用，不调用被标为 legacy 的旧生成流程。

## 精修与保存

读取最新设计 → 开始编辑事务 → 对现有对象执行操作 → 检查每个操作的结果和各修改页预览 → 按当前工具规则取得必要批准并提交 → 核对已保存结果。

根据当次 schema 检查文字替换、字号／字重／颜色／行距、对象位置和尺寸等操作。部分接口可能不能新建文本框或更换字体家族；遇到当前工具不支持的返修，清楚列出需要人工调整的页面、对象和目标，不用重建旧页面绕过并覆盖人工编辑。

按当前提交工具要求展示修改、取得必要批准并提交；以成功提交结果确认保存。

人工与 Agent 的编辑应接力。提交遇到并发冲突时，不重复提交旧事务；读取最新设计后重新开始。如果只读取了事务而无需修改，按当前工具规则取消事务。

页面增删复制等结构操作与文本编辑是不同能力；需要时检查当前专用工具，不把编辑接口的限制扩大成整个平台的限制。

保存设计 ID、页 ID、关键元素 ID 和母版关系，返修前重新定位；不要在长期交接中保存临时事务或上传令牌。
